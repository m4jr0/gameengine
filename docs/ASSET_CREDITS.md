# Asset Credits

This document lists third-party assets used for testing and demonstration purposes in **Comet**.

## Dancing Vampire Model

This model is from the [LearnOpenGL](https://learnopengl.com/) tutorial series.

Original source: https://github.com/JoeyDeVries/LearnOpenGL/tree/master/resources/objects/vampire

## Eve By J.Gonzales

This folder contains character animations combined into a single file.

* Model and source animations provided by **Adobe Mixamo** (https://www.mixamo.com).
* Animations were combined manually in Blender.

## Sponza Atrium Scene

This scene uses the Sponza Atrium model from the official glTF Sample Models repository, maintained by the Khronos Group.

**Source:** https://github.com/KhronosGroup/glTF-Sample-Models/tree/main/2.0/Sponza
